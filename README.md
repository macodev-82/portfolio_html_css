# Maahcodev Portfolio

Personal portfolio landing page for **Marcos Alvarez — Maahcodev**, focused on Python backend and full-stack web development.

**Live website:** https://maahcodev.dev/

## Overview

This portfolio presents Maahcodev's technical capabilities, selected private projects in active development, available services, development workflow, and contact channels.

The interface follows a terminal-editorial visual direction and is designed to remain clear, accessible, responsive, and usable across desktop, tablet, and mobile devices.

## Main features

- Spanish and English interface
- Dark and light themes with local preference persistence
- Responsive layout from small mobile screens to desktop
- Accessible mobile navigation and keyboard interaction
- Reusable project case-study dialog
- Reduced-motion support
- Contact form powered by Formspree
- SEO, Open Graph, and Twitter metadata
- Custom Maahcodev branding and favicon

## Technologies

- HTML5
- CSS3
- JavaScript
- Formspree
- Google Fonts

The projects presented inside the portfolio also reflect practical work with technologies such as Python, FastAPI, HTTPX, pytest, Jinja2, Tailwind CSS, Git, Linux, and Ubuntu.

## Featured work

The featured projects are private and currently in active development. The portfolio presents sanitized descriptions, documented milestones, verified features, and technology summaries without exposing private repositories or sensitive infrastructure.
