Sobre mí

Soy un desarrollador web autodidacta basado en Miami, FL. Empecé con curiosidad genuina sobre cómo funciona internet por dentro — y eso me llevó a construir este portafolio desde cero, línea a línea, sin atajos.

Mi stack actual incluye HTML y CSS para la web, Python para scripting y lógica, y Linux/Ubuntu como entorno principal de trabajo. Uso Git y GitHub para versionar cada proyecto desde el primer commit.

Mi meta no es solo escribir código — es entender por qué funciona. Cada proyecto que construyo es una oportunidad de aprender algo que no sabía el día anterior.

Me enfoqué en entender la web de verdad: HTML semántico, Flexbox, Grid, responsive design — sin frameworks, sin atajos. Cada propiedad, entendida.

2025

2025

Empecé a versionar todo desde el primer commit. Comprendí el flujo de trabajo profesional: ramas, pull requests, historial limpio.
